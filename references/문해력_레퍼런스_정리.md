# 문해력 레퍼런스 정리 — 낱말탑 설계 근거

Oct 12, 2026 · @김원진

## 문해력이란

**문해력은 글을 읽고 배경지식으로 의미를 스스로 구성하고, 그 내용을 판단해 삶과 학습에 쓰는 능력이다.** 국가 교육과정과 국제 기준이 같은 방향을 가리킨다.

- **국가 교육과정(2022 개정):** 언어·수리·디지털 소양을 모든 교과 학습의 바탕인 '기초소양'으로 강조한다 ([대학저널](https://dhnews.co.kr/news/view/179523951356909)). 국어과 읽기의 핵심 아이디어는 '독자가 배경지식과 경험을 활용해 글의 의미를 능동적으로 구성하는 행위'다 (아래 '내용 체계 요약').
- **교육부:** 제1차 기초학력 보장 종합계획(2023\~2027)은 문해력을 기초학력의 출발점으로 보고, 초1\~2 한글 익힘 시간을 448시간에서 482시간으로 늘렸다 ([한국교육신문](https://hangyo.com/news/article.html?no=97365)).
- **국제(PISA):** 읽기 소양을 목표 달성, 지식 확장, 사회 참여를 위해 글을 이해·활용·평가·성찰하는 능력으로 정의한다 ([PISA HKU](https://pisa.hku.hk/domains/reading-literacy/)).

## 낱말탑에 주는 시사점

**공격 속성 4개는 교육과정 범주에 1:1로 붙일 수 있고, 나머지 두 범주는 게임 규칙으로 담는다.**

| 낱말탑 속성 | 지금 문항 태그 | 교육과정 근거 |
| --- | --- | --- |
| 낱말 베기 | 문맥 낱말 | 문맥으로 뜻 짐작 (어휘) |
| 연결 사슬 | 문장 연결 | \[6국02-01\] 구조로 내용 파악 |
| 추리의 눈 | 내용 추론 | \[6국02-02\] 생략·함축 추론 |
| 근거 방패 | 근거 판단 | \[6국02-03\] 타당성 평가 |

- **점검과 조정** → 규칙으로: 다시 읽기는 공짜, 찍기는 손해. 스스로 이해를 확인하는 습관이 유리해진다.
- **가치·태도** → 재미 자체: 읽기 동기를 기르는 게 게임의 존재 이유다.
- **빈칸:** \[6국02-04\] 여러 관점의 글로 문제 해결은 아직 문항이 없다. 보스층(두 글 비교)으로 넣을 수 있다.

**교육과정이 직접 뒷받침하는 기능:** \[6국02-02\] 해설은 '중요 단어나 문장, 문단 수준에서 의미 추론하기'를 학습 내용으로 든다. 적용 시 고려 사항은 '나만의 단어 사전이나 단어 기록장'과 '자기 점검표'를 권한다. 낱말 베기 속성, 낱말 수첩, 약점 스탯이 여기에 그대로 맞는다 (레퍼런스 00번, 38쪽 17\~21줄, 39쪽 17·20줄).
