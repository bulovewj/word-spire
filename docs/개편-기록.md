# 재미 개편 기록 (2026-11-10 ~ 11-12)

사용자 지시: "초등학생들이 즐길 재밌는 게임이 되도록 스토리·엔진·구조·콘텐츠·디자인·레이아웃을 마음대로 고쳐 봐."
`docs/기획안.md`는 손대지 않았다. **이 문서가 기획안 6장과 다른 곳을 적은 기준**이고, 여기 없는 규칙은 기획안 그대로다.
커밋하지 않은 상태다. 되돌리려면 `git checkout -- src` + 새 파일 삭제.

## 0. 왜 고쳤나 (진단)

- 균형 시뮬레이션에 '보통 학생'(10문제 중 7개 맞힘)을 넣어 보니 **탑을 한 번에 다 오를 확률 13%**, 다시 하기를 써도 48%. 3층이 벽이었다.
- 낮은 체력으로 3층에 들어가면 다시 해도 같은 체력이라 영영 못 깨는 경우가 있었다.
- 방어가 '뜻 타이핑'뿐이라 폰·느린 타자에서 버거웠다. 낱말 30개 중 6개만 쓰였다.
- 전투 화면이 양식처럼 보였고 타격감·성장·모으는 재미가 없었다. 웨일북(1366×650)에서 한 화면에 안 들어왔다.

## 1. 이야기

- 세계관(왕명과 닫힌궁)·주인공·요괴 이름은 그대로. 세 요괴를 **되풀이해 나오는 '요괴 삼총사'**로 삼았다(새 그림 없이 탑을 늘릴 수 있다).
- 처음 한 번 보는 **프롤로그 3장면**(건너뛰기 가능), 모든 탑을 봉인하면 나오는 맺음 두 줄 — `content/story.ts`.
- 요괴가 전투 중에 한마디씩 한다(맞았을 때·내가 틀렸을 때·공격·막혔을 때 등) — `content/yokai.ts`. 정답·낱말 뜻의 단서가 되지 않게 썼다.

## 2. 규칙에서 바뀐 것 (기획안 6장과 다른 곳)

| 무엇 | 전 | 지금 | 까닭 |
|---|---|---|---|
| 층 사이 체력 | 이어짐, +8 | **층마다 가득 회복** | 한 층이 한 번의 자투리 시간. 앞 층 실수로 다음 층이 막히지 않게 |
| 다시 하기 | 층 시작 체력 그대로 | 체력 가득 + **요괴 공격 -1씩(최대 -3)** | 서툰 학생도 끝내 오르게. 화면에 "지친 요괴"로 보임 |
| 낱말 방어 | 뜻 쓰기 +5 | **뜻 고르기 +5 / 뜻 쓰기 +8** | 폰·느린 타자 배려. 고르기는 기록에서 '도움받아 해결' |
| 연속 정타 | 없음 | 정타마다 피해 +1(최대 +4), **3번째마다 생각력 +1** | 정확히 읽을수록 신난다. 탑 안에서 층을 넘어 이어짐 |
| 층 별 | 없음 | ★봉인 ★질문 모두 정타 ★체력 절반 이상 | 다시 오를 까닭. 헛소문은 별 조건에서 뺌(간이 채점에선 통과 불가) |
| 층 보상 | 안개 낱말 | 안개 낱말 + **셋 중 하나 고르기**(보물 2 + 새 낱말 1) | 고르는 재미, 안 쓰이던 낱말 24개가 나옴 |
| 요약 | 실패 시 빠진 개념 안내 | + **2번 실패하면 요약 틀**(모범 요약의 핵심 낱말을 비운 문장) | 요약에서 갇히지 않게. 기록은 '도움받아 해결' |
| 적 공격 | 6·8·6 / 7·5·9 / 8·6·9·7 | 6·8·7 / 6·5·10 / 7·5·8·6 | 2층은 '큰 공격' 한 방, 3층은 조금 순하게 |

보물 5종(`engine/boons.ts`, 숫자는 `balance.ts`): 약수 호리병(최대 체력 +6) · 청심 매듭(낱말 방어 +2) · 돌문진(층마다 첫 공격 -4) · 밝은 등불(층마다 단서 1번 공짜) · 굳센 붓(정타 피해 +2).

그대로인 것: 생각력 3, 질문 3종과 피해, 근거 판정, 확신도(×1.5 / +3), 안개 보호막, 헛소문, 요약으로만 봉인, 낱말 탑당 2번, 채점 방식·기준값, 기록·결과 코드·교사 화면.

## 3. 구조

- `engine/`: `state.ts`(형식·reduce)에서 규칙을 파일로 나눔 — `question` `defend` `seal` `rumor` `support` `battle` `select`. 새로 `boons` `stars` `profile`, 시뮬레이션용 `simPolicies`.
- `STATE_VERSION` 8, `RUN_VERSION` 4 → 옛 이어하기는 숨겨진다. 판정 기록(스탯)은 그대로 남는다.
- 성장 기록(`Profile`: 층별 최고 별·왕명 인장·모은 낱말·요괴 봉인 수)과 설정(소리)을 `storage/store.ts`에 따로 저장.
- `ui/useGame.ts`가 상태를 쥐고 `App.tsx`는 화면만 고른다. 전투 화면 부품은 `ui/battle/`.

## 5. 콘텐츠

- **한글 탑 추가**(`passages/hangul-1~3.ts`, `towers/hangul.ts`) — Claude 초안, **사용자 사실·난도 검수 전**.
  - 1층 「백성을 위한 글자」: 한자를 빌려 씀, 배우기 어려움, 세종이 안타깝게 여겨 새 글자, 훈민정음의 뜻.
  - 2층 「소리를 닮은 글자」: 자음 기본 다섯 자는 소리 내는 곳의 모양, 획을 더함(소리가 셀수록), 모음은 하늘·땅·사람, 합쳐서 늘림.
  - 3층 「기록이 말해 주는 한글」: 해례본에 만든 사람·까닭·원리, 반대한 신하들, 유네스코 세계 기록 유산. 헛소문 "기록이 하나도 없다".
  - 검수해 줄 곳: ① "다른 자음 글자는 **대부분** 획을 더해"(ㄹ 등 예외를 '대부분'으로 처리) ② "누가 언제 만들었는지 알려진 글자는 **드물다**" ③ 2층 요약·3층 반박의 핵심 개념 동의어(실제 학생 답으로 `?dev=grading`에서 확인 필요 — 이번엔 모범 요약으로 봉인되는 것만 확인).
- 한글 탑의 처음 낱말 묶음은 말·글에 얽힌 낱말(배려·근거·귀가 얇다·입이 무겁다·속담 2개) — `Tower.starter`.
- 데이터 검사 추가: 탑마다 1·2·3층이 하나씩, 잠긴 낱말은 본문에 한 번만, 단서 문장은 낱말이 있는 문장이 아닐 것.
- 꿀벌 탑은 적 공격 숫자와 탑 소개 한 줄(`blurb`)만 바뀌었다. 글·문항은 그대로.

## 6. 화면

- 흐름: 처음 → (프롤로그) → **닫힌궁(탑 고르기)** → 탑 소개 → 전투 → 보상 고르기 → … → 탑 완료(왕명 인장) / **부적첩**(낱말·요괴 도감) / 내 기록 / 선생님.
- 전투: 왼쪽 본문 | 오른쪽 **밤 서고 무대**(그림 2배) · 손패(부적패 카드, 도장 한 글자) · 아래 막대. 한 화면에 고정, 넘치면 그 칸만 스크롤.
  - 질문은 **① 답 → ② 근거 → ③ 확신** 세 단계. 확신 단추가 곧 공격.
  - 떠오르는 피해 숫자, 맞은 쪽 번쩍, 무대 흔들림, 요괴 말풍선, 체력바 예고 줄무늬(유지), 틀리면 정답 근거를 본문에 초록 테두리로.
  - 첫 전투에 '길잡이 마패' 안내(도움말 단추로 다시 보기), 층에 들어서면 먼저 글 읽기.
- 크기별: 컴퓨터·패드 가로는 2단, 패드 세로·폰은 무대→본문→손패 한 줄. 폰은 그림 1배, 손패 3칸 타일, 패널이 열리면 무대를 접어 본문 자리를 넓힘.
  확인한 크기(헤드리스 크롬): 1366×650, 1440×900, 1180×820, 1024×768, 820×1180, 390×844, 360×640. **실기기(웨일북·아이폰·패드) 확인은 아직.**
- 효과음: 파일 없이 WebAudio로 만듦. **처음엔 꺼져 있고** 학생이 켠다(교실 배려).
- 무대 배경·도장·단청 띠는 그림 파일 없이 CSS다. 새 그림 파일은 넣지 않았다.

## 7. 못 한 것 · 알아 둘 것

- 단잠 탑(잠과 몸·뇌)은 설계만 하고 넣지 않았다. 픽셀 이펙트(pixelfx)와 '근거 문장이 요괴에게 날아가는' 연출도 안 했다.
- 한글 탑의 서술형 채점은 실제 학생 답으로 검증하지 않았다.
- `검토/보조자료/컴퓨터패드-시안.tsx`(Codex 시안)는 옛 `BattleScreen`을 가져다 써서 **다시 빌드되지 않는다**(만들어 둔 HTML은 그대로 열림). `검토/` 폴더는 건드리지 않았다.
- 에셋 대장·장면 보드는 갱신하지 않았다(새 그림 파일이 없어서). CSS 배경을 대장에 올릴지는 사용자 판단.
