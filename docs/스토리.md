# 낱말탑 스토리 설정집 — 왕명과 닫힌궁

2026-10-21 · Codex · `story` 브랜치. 사용자가 정한 새 세계관의 문서 원본이다.
문구·요괴 이름·새 그림의 실제 게임 반영은 후속 콘텐츠·화면 작업으로 인계한다. 이번에는 설정과 디자인 요청서를 갱신한다.
정보글은 확인 가능한 사실만 담고, 왕·궁·요괴의 허구는 이야기 영역에 둔다. 전투·채점 규칙은 현행 `docs/기획안.md` 6장을 따른다.

## 1. 세계관과 전체 이야기

가상의 나라에, 글을 읽어도 뜻을 놓치고 근거 없는 소문부터 믿게 되는 일이 벌어졌어.
요괴들이 낱말의 뜻을 흐리고 문장의 앞뒤를 뒤섞어 사람들의 **글힘**을 약하게 만든 뒤, 헛소문으로 나라를 어지럽히고 있었지.
**글힘**은 ‘글을 읽고 뜻을 이해하며, 근거를 살펴 판단하는 힘’이야. 세계관에서 문해력을 쉽게 부르는 말이며 새 수치나 자원이 아니야.
왕은 글과 도술을 함께 익힌 ‘나’에게, 요괴를 봉인하고 사람들이 다시 글을 살필 수 있도록 길을 열라는 명령을 내려.
평소 문이 잠겨 있는 **닫힌궁**은 왕명이 담긴 마패를 지닌 사람에게만 길을 열어 줘. 문 안에는 요괴가 가린 글들이 화제별 탑에 흩어져 있어.
한 탑은 화제 하나·세 층이야. 아래층의 글을 이해한 것이 다음 층의 발판이 되고, 꼭대기의 요괴를 봉인하면 되찾은 글을 궁 밖에 전할 수 있어.
왕명은 여정을 시작하는 이유이고, 무엇이 맞는지는 글의 근거를 찾아 판단해. 사람들이 스스로 읽고 설명할 힘을 되찾는 것이 임무의 목적이야.

| 이야기 흐름 | 학생이 하는 일 | 도달하는 장면 |
|---|---|---|
| 왕명을 받고 닫힌궁에 들어감 | 탑 소개 두 줄을 읽고 화제를 고름 | 왕명 마패와 열린 궁문 |
| 1층: 흐려진 낱말을 되찾음 | 뜻의 단서·직접 근거를 찾음 | 도깨비의 안개가 걷힘 |
| 2층: 끊긴 글의 관계를 이음 | 문장들을 연결하고 이유를 설명함 | 호랑이가 뒤섞은 길을 통과 |
| 3층: 글 전체를 내 말로 묶음 | 글을 바탕으로 판단하고 한 문장으로 요약함 | 여우의 헛소문을 호리병에 봉인 |
| 임무를 마침 | 새 낱말을 챙기고 글을 궁 밖에 전함 | 마을에 되찾은 글이 돌아감 |

궁과 왕명은 현재 탑 선택·입장·완료의 이야기로 표현한다. 별도의 궁 이동·실제 시간대에 따른 문 열림·긴 대화는 추가하지 않는다.
3층도 기존 질문 3종을 모두 사용한다. 위 표는 층의 이야기 강조점이며 카드 종류를 층별로 제한한다는 뜻이 아니다.

### 읽기 장치가 도술이 되는 까닭

| 기존 게임 장치 | 이야기에서의 뜻 |
|---|---|
| `▒▒`·안개 보호막 | 요괴가 뜻을 흐린 자리. 주변 문장에서 단서를 찾아 뜻을 밝히면 안개 보호막이 풀림 |
| 질문·근거 | 답과 근거를 맞추면 글줄이 부적패의 길로 이어져 요괴의 힘을 약하게 함. 답만 맞으면 연결이 약함 |
| 낱말 방어 | 뜻을 내 말로 쓰면 내가 아는 낱말의 부적패가 펼쳐져 안개를 막음 |
| 낱말 수집 | 안개를 걷어 되찾은 낱말은 층 보상에서 내 낱말 묶음으로 들어옴 |
| 요약 봉인 | 적 체력 40% 이하 또는 질문을 다 쓴 뒤 해금. 성공한 요약이 안개를 한데 묶어 호리병에 담고 도장으로 닫음 |
| 생각력 3 | 한 턴에 나누어 쓸 집중력. 마패풍 표식으로 보이되 ‘생각력 N’ 글자와 숫자를 함께 표시 |
| 확실·애매 | 내 판단을 점검하는 선택. 현행 피해·벌·다음 단서 보기 규칙을 그대로 따름 |

‘퇴치’는 요괴의 소동을 멈춘다는 줄거리 표현이다. 실제 마무리는 종이·안개로 접어 호리병에 **봉인**하는 장면이며 피·상처·무기 타격은 없다.
왕명 마패는 입장 자격을 설명한다. 생각력 표식 3개는 그 문양을 빌린 작은 UI 표식이며, 입장권을 세 번 소모하는 규칙이 아니다.

## 2. 주인공 ‘나’

- 이름·성별·나이는 정하지 않는다. 왕명을 받은, 글과 도술을 함께 익힌 문무 탐험가다.
- 현재 승인된 캐릭터 유지: 검은 머리와 낮은 묶음머리, 먹빛 현대 한복 재킷, 크림색 겹깃, 세이지 안감·카고 주머니·발목 신발, 등판의 금빛 원형 용 문양.
- 손에는 한지 부적패, 허리에는 카드 수납함과 호리병. 마패와 도장은 임무와 봉인을 나타내는 도구다.
- 궁금하면 다시 읽고, 모르면 망설임을 말하며, 근거를 살펴 자기 말로 설명한다. 실패하면 같은 층에서 다시 도전한다.

## 3. 화면에 쓸 짧은 이야기

각 줄은 공백 포함 40자 안팎. 왕명 원문은 설정용이며, 별도 프롤로그 화면은 이번에 추가하지 않는다.

| 자리 | 첫째 줄 | 둘째 줄 |
|---|---|---|
| 왕명 원문 | 요괴가 글을 흐리고, 헛소문으로 나라를 어지럽혀. | 닫힌궁으로 들어가 글을 되찾고, 소문을 가릴 길을 열어 줘. |
| 꿀벌 탑 입장 | 왕명을 받아 닫힌궁의 꿀벌 탑에 들어왔어. | 요괴가 가린 글에서, 소문을 가려낼 근거를 찾아봐. |
| 꿀벌 탑 완료 | 세 층의 글을 네 말로 묶어 요괴를 호리병에 봉인했어. | 되찾은 글을 마을에 전하고, 새 낱말도 챙겨 가자. |

한 탑 완료는 그 화제의 임무를 마친 것이다. 여러 탑을 잇는 전체 여정의 끝에는 사람들이 소문을 그대로 옮기기보다 글의 근거를 서로 설명하는 모습을 보여 준다.
등장 대사는 본문 사실·잠긴 낱말의 뜻·정답 보기의 단서가 되지 않게 쓴다. 요괴가 퍼뜨린 구체적인 거짓 문장을 정보글에 삽입하지 않는다.
공통 패배 문구는 “쓰러졌어. 이 층부터 다시 도전해 봐.”, 승리는 “봉인했어!”를 유지한다.

## 4. 요괴 세 종

모두 종이·안개로 된 허구의 요괴다. 실제 호랑이·여우를 해치는 이야기가 아니다. 새 이름과 그림 id는 다음 연결 작업의 기준이다.

| 층 | 새 이름·새 아트 id | 모습과 이야기 역할 | 등장 한 줄 | 봉인 한 줄 |
|---|---|---|---|---|
| 1 | 먹안개 도깨비 · `dokkaebi` | 둥근 코·굵은 눈썹·통통한 몸·세이지 조끼. 낱말을 안개로 흐려 놓는 장난꾸러기 | 내 안개를 지나 다음 층에 갈 수 있겠어? | 앗, 내 안개가 호리병 속으로 접히잖아! |
| 2 | 뒤섞는 호랑이 · `tiger` | 민화풍 둥근 얼굴·황토빛 털·먹빛 줄무늬·휘어진 꼬리. 글의 앞뒤를 뒤섞어 길을 헷갈리게 함 | 이 문 앞에선 큰소리도 소용없을걸? | 크르릉, 이번에는 네가 길을 찾았구나. |
| 3 | 헛소문 여우 · `fox` | 크림 털·라벤더 꼬리·먹빛 겹깃 옷. 참말 조각에 거짓을 보태 소문을 퍼뜨리는 탑의 우두머리 | 여기까지 왔네. 마지막 문도 열 수 있을까? | 내 소문이 한 장의 부적에 묶이다니! |

요괴의 장난은 허구의 이야기다. 현재 정보글의 문장 순서·정확한 사실을 실제로 바꾸는 전투 효과로 구현하지 않는다.

## 5. 아트와 도구

[한국풍 키 아트·주인공](design/한국풍-아트-수정안.md)과 [부적패·호리병 봉인](design/부적패와-호리병-봉인.md)을 기준으로 삼는다.
닫힌궁 안은 한지·목조 기둥·창살·단청·등불이 있는 서고탑이다. 책장 계단과 위층 세 요괴의 구도, 밝은 종이 톤, 먹빛 외곽선, 세밀한 도트를 유지한다.
캐릭터 본색은 2~3계열과 제한된 단계 음영으로 정리하고, 기존 32×32·48×48 격자를 상한으로 삼지 않는다. 화면 표시 크기에 맞는 셀과 정수 배율을 택한다.
질문·낱말은 같은 크기의 가로 한지 부적패, 생각력은 마패풍 표식, 봉인은 호리병·네모 도장이다. 문구는 Galmuri HTML로 얹고 그림에 정답·읽을 글자를 넣지 않는다.
요약 성공 뒤 부적 펼치기→안개를 호리병에 담기→마개와 도장으로 봉인, 총 720ms 제안. 움직임 줄이기는 닫힌 호리병+결과 문구를 즉시 표시한다.

## 6. 데이터·구현 인계와 성장 구상

기존 `Tower.intro/outro`와 `Enemy.name/sprite/introLine/sealLine`, 주인공 상수로 현재 이야기 연결이 가능하다. 이번에 새 타입·저장 형식·프롤로그 화면을 만들지 않는다.

| 다음 연결 위치 | 인계할 내용 |
|---|---|
| `src/content/towers/bee.ts` | 3장의 꿀벌 탑 입장·완료 두 줄 |
| `src/content/passages/bee-1.ts` | 기존 가뭄 도깨비·`drought` → 먹안개 도깨비·`dokkaebi`, 새 등장·봉인 대사 |
| `src/content/passages/bee-2.ts` | 기존 빈꽃 도깨비·`bloomgap` → 뒤섞는 호랑이·`tiger`, 새 등장·봉인 대사 |
| `src/content/passages/bee-3.ts` | 기존 지움 안개왕·`erasure` → 헛소문 여우·`fox`, 새 등장·봉인 대사 |
| `src/ui/sprites/` | 승인된 복식과 새 요괴의 실제 게임용 시트·호리병 봉인 프레임. 기존 PNG는 이전 초안 |

정보글·문항·근거·잠긴 낱말·요약 채점·전투 수치는 이번 스토리 변경으로 고치지 않는다. 현재 게임에는 이전 적 이름·문구가 남아 있으므로, 위 표를 한 번에 연결한다.
강화·아이템은 **[성장과 아이템 구상](design/성장과-아이템-구상.md)**에 설계 아이디어만 적었다. 권장 방향은 낱말 수집·왕명 인장과 작은 선택형 장비다. 효과 수치·상점·해금·보상 코드는 구현하지 않는다.

문항 최종 기준은 `docs/codex-요청.md`의 **기존 요청 3 처리 결과**와 실제 `bee-2.ts`·`bee-3.ts`다. 이번 ‘디자인 브리프 전체 갱신’과는 다른, 완료된 검수 이력이다.
요청 3에서 2층 연결은 `count: 2, required: [[2], [3]], allowed: [0, 1, 4, 5]`로 정리했다. 정답 보기를 고른 뒤 근거만 균등하게 찍으면 정타는 9/21이다.
2층 글쓴이와 나는 `count: 1, required: [[3], [6]]`, 3층 글쓴이와 나는 `count: 1, required: [[3], [4]]`다. 직접 근거 2개씩으로 정타 근거 비율은 2/7·2/8이다.
3층 연결은 `count: 2, required: [[1]], allowed: [3, 4, 5, 6, 7]`로 5/28이다. index는 0부터이며, 두 3층 정답은 본문을 다른 말로 쓰고 표현이 겹치지 않게 했다.
2층 보너스는 1층 ‘위협’(`bee-w1`), 3층은 2층 ‘공급’(`bee-w2`)이다. 모범 요약·핵심 개념·반대 뜻 앵커와 이 출처 표는 유지한다.
과거 문항 검수 기록: 요청 3에서 테스트 109개·빌드 통과. 실제 학생 답의 의미 채점과 어휘 난도는 계속 사용자 검수 대상이다.
