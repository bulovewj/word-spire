# 낱말탑 교사 안내서

2026-11-17 · 꿀벌·한글 탑 배포판

## 수업 준비

초등 5~6학년이 정보글을 읽고 답과 근거를 연결하며 낱말 뜻과 한 문장 요약을 연습하는 게임입니다. 한 탑은 3층이고 한 층은 5~10분입니다. 한 차시에는 한 층을 권합니다.

수업 전에 같은 기기·브라우저로 게임을 열어 의미 채점 준비를 확인해 주세요. 첫 모델 다운로드는 약 120MB이며 학교망과 캐시에 따라 달라집니다. 준비 중이나 오류 때는 간이 채점으로 진행할 수 있습니다. 오프라인 실행을 보장하지는 않습니다.

## 진행 방법

1. 모험 시작 → 닫힌궁에서 탑을 고릅니다.
2. 본문을 읽고 질문의 보기 → 근거 문장 → 확신도를 고릅니다.
3. 낱말 뜻 고르기(방어 5) 또는 뜻 쓰기(방어 8)로 공격을 막습니다.
4. 요괴가 약해지거나 질문을 모두 쓰면 요약으로 봉인합니다.
5. 보상 하나를 고르고 다음 층으로 갑니다. 다음 층은 체력이 가득 찹니다.

패배하면 같은 층에 다시 도전할 수 있고, 요괴 공격이 최대 3 약해집니다. 낱말은 탑마다 2번 사용할 수 있습니다. 요약을 두 번 실패하면 요약 틀이 나옵니다. 별은 봉인·질문 모두 정타·체력 절반 이상 조건으로 얻습니다.

## 결과 모으기

학생은 ‘내 기록’에서 이름을 입력하고 ‘결과 코드 복사’를 누릅니다. 학교에서 정한 제출 경로로 코드를 받으신 뒤 ‘선생님’ 화면에 한 줄에 하나씩 붙여 넣고 ‘표 만들기’를 누르세요. 깨진 코드는 해당 줄만 안내합니다.

정답률은 같은 진행·같은 층의 첫 시도 중 도움 없이 정타로 해결한 비율입니다. 약타는 오답으로 셉니다. 단서·뜻 고르기·요약 틀의 성공은 ‘도움받아 해결’로 따로 표시합니다. 판단력은 확실·애매 응답이 각각 5개 이상일 때 표시됩니다. 약점도 충분한 표본이 있을 때만 표시합니다.

교사 표는 저장되지 않으며 화면을 나가거나 새로 고치면 사라집니다. 제출받은 코드는 따로 보관해 주세요. 누적 결과이므로 같은 학생의 코드를 여러 번 넣으면 중복 집계됩니다.

## 채점과 저장의 한계

자동 의미 채점은 오판할 수 있습니다. 간이 요약은 길이와 핵심 개념만 검사하며, 간이 반박은 통과로 인정하지 않습니다. 학생의 설명과 본문 근거를 함께 확인해 주세요. 실제 학생 답으로 표현별 채점과 난도를 추가 점검해야 합니다.

진행·성장 기록·이름은 같은 주소의 같은 브라우저 프로필에만 저장됩니다. 저장이 차단되거나 기기 데이터를 삭제하면 이어하기가 사라질 수 있습니다. 공용 프로필에서는 학생 기록이 섞입니다. 계정이나 서버 저장 기능은 없습니다.

결과 코드에는 이름과 집계 수치만 들어 있으며 학생이 쓴 답은 들어 있지 않습니다. 소리는 기본으로 꺼져 있습니다. 기기의 ‘움직임 줄이기’ 설정을 지원합니다. 웨일북·아이패드·휴대전화 실기기에서 수업 전 입력과 스크롤을 확인해 주세요.
