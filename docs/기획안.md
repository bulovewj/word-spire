## 1. 한 줄 요약

글을 읽고, 근거를 찾고, 스스로 이해를 점검하는 **읽기 루틴**을 카드 전투로 바꾼 문해력 게임.
읽기를 정확히 할수록 세게 때린다.

## 2. 방향 (형 결정 사항)

- 공모전에 내지 않고 따로 개발한다.
- 학년군 팩 3개(1~2 / 3~4 / 5~6). 엔진은 하나, 글·문항 데이터만 다르다. **5~6학년 팩부터 끝까지 만든다.**
- 사용 장면: 수업 자투리 시간. 한 층 = 5~10분.
- 슬더스는 형식(카드, 에너지, 적 공격 예고, 층 오르기)만 빌린다. 이름·카드·그림은 전부 새로 만든다.
- 그림은 도트.
- 틀리면 낸 카드는 실패한다.
- 서술형 답은 문장 의미 유사도(코사인)로 채점한다. 생성형 AI는 실행 중에 쓰지 않는다.
- 서버·계정 없음. 기록은 학생 기기에만.

## 3. 해결하려는 문제

이전 버전은 아무거나 눌러도 이기고, 체력 변화가 안 보였다.
1. 틀려도 대가가 없다 → **카드 실패 + 확신도 베팅**
2. 정보가 숨어 있다 → **적 공격 예고, 내 체력바에 받을 피해 미리 표시**

## 4. 교육 근거: 읽기 루틴 4개 → 게임 장치

| 루틴 | 학생이 실제로 하는 것 | 게임 장치 |
|---|---|---|
| 어휘 | 낱말 앞뒤 문장에서 뜻의 단서 찾기 | **안개 걷기** (잠긴 낱말) → 낱말 카드 |
| 묻고 답하기 | 질문 3종에 답하고 근거 문장 대기 | **질문 공격** |
| 핵심 요약 | 중요한 것만 모아 내 말로 한 문장 | **요약 봉인** (마무리 일격) |
| 이해 점검 | "확실한가?" 스스로 묻기 | **확신도** (확실/애매) |

교육과정(5~6): [6국02-01] 요약, [6국02-02] 추론, [6국02-03] 평가, [6국02-05] 읽기 동기.

## 5. 한 판 해 보기 (예시)

> 탑 "꿀벌" 1층. 적: 가뭄 도깨비 (체력 40, 다음 공격 6). 내 체력 40.

**전투 시작.** 화면 왼쪽에 글 5문장이 번호와 함께 뜬다. 5번 문장의 "**위협**"이 안개로 가려져 있다. 안개가 있는 동안 적은 **안개 보호막**(내 질문 피해 -2)을 쓴다.

**1턴 (생각력 3)**
- 손패: 질문 카드 3장(거기 있음 / 연결 / 글쓴이와 나) + 낱말 카드 2장(지난번에 모은 "협력", "절약").
- 먼저 **안개 걷기**(1): "위협의 뜻을 짐작하게 해 주는 문장을 골라 봐" → 3번 문장(꿀벌 수가 줄고 있다)을 탭 → 정답. 안개가 걷히고 "위협" 낱말 카드를 이번 판 보상으로 예약. 보호막 해제.
- **질문: 거기 있음**(1): "과학자들이 꼽은 원인은?" → 보기 ① 농약과 기후 변화 선택 → 근거로 4번 문장 탭 → 확신도 **확실** → 정타 6 × 1.5 = **9**. 적 체력 31.
- 생각력 1 남음. 낱말 카드 "협력"(1): 뜻을 서술 "힘을 합쳐 돕는 것" → 통과 → **방어 5**.
- 턴 끝 → 적이 6 공격, 방어 5로 막아 **1**만 받음. 내 체력 39. 다음 예고: 8.

**2턴**
- **질문: 연결**(2): "꿀벌이 줄면 왜 밥상이 위협받을까?" → ① 선택, "근거 문장 2개를 골라 봐" 안내에 따라 2번·5번 탭(5번은 질문을 되풀이한 문장이라 근거가 못 됨. 필요한 건 2번 + 1번이나 3번) → 확신도 **애매** → 해석은 맞고 근거가 틀려 **약타** 5. 적 체력 26. 애매로 걸었기 때문에 받는 벌 없음.
- 낱말 카드 "절약"(1): "돈을 많이 씀" → 반대 뜻 → **카드 실패**, 정답 뜻이 화면에 뜸.
- 턴 끝 → 8 피해, 내 체력 31.

**3턴**
- **질문: 글쓴이와 나**(2): 정타 14. 적 체력 12 → 40% 이하라 **요약 봉인 카드**가 손패에 나타남.
- 생각력 1 남음, 요약은 2라서 이번 턴은 못 냄. 턴 끝 → 6 피해.

**4턴**
- **요약 봉인**(2): "꿀벌이 줄어들면 과일과 채소도 줄어서 밥상이 위험해진다" → 핵심 3개(꿀벌 / 줄어듦 / 먹거리) 다 있음 + 의미 통과 → **처치!**
- 보상: "위협" 낱말 카드 덱에 추가, 체력 10 회복 → 2층으로.

이 예시에서 학생은 낱말 단서 찾기 1번, 근거 대며 질문 3번, 낱말 뜻 쓰기 2번, 요약 1번을 했다. 약 7분.

## 6. 규칙 상세

### 6-0. 덱
- **덱 = 낱말 카드 묶음 = "내가 아는 낱말".** 질문 카드는 덱이 아니라 글에 딸려 온다.
- 처음 덱: 기본 낱말 팩에서 6장(5~6학년 팩 기준 "협력, 배려, 근거, 존중, 절약, 책임" = `h01, h02, h03, h07, h08, h10`).
- 안개를 걷은 낱말이 층 보상으로 덱에 들어간다. 탑을 오를수록 덱이 커진다.

### 6-1. 턴
- 생각력 3/턴. 쓰지 않은 생각력은 사라진다.
- 손패는 두 종류다.

| 종류 | 카드 | 언제 손패에 있나 | 턴이 끝나면 |
|---|---|---|---|
| **글 카드** (글에 딸려 옴, 뽑지 않음) | 질문 카드 | 처음부터, 쓸 때까지 | 남는다 |
| | 안개 걷기 | 잠긴 낱말 하나당 1장, 걷을 때까지 | 남는다 |
| | 요약 봉인 | 적 체력 40% 이하가 되거나 질문 카드를 다 쓴 순간부터, 성공할 때까지 | 남는다 |
| **낱말 카드** (덱에서 뽑음) | 낱말 카드 | 매 턴 2장 뽑기 | 버린 더미로 |

- 안개 걷기·요약 봉인을 실패하면 그 카드는 **이번 턴 동안 잠기고** 다음 턴에 다시 쓸 수 있다.
- **단서 보기는 카드가 아니라 질문 패널 안의 버튼**이다(생각력 1). 손패 자리를 차지하지 않는다.
- 턴 끝: 적이 예고한 만큼 공격. 내 방어는 턴 시작 때 0.

### 6-2. 카드

| 카드 | 비용 | 하는 일 | 결과 |
|---|---|---|---|
| 안개 걷기 | 1 | 잠긴 낱말의 단서 문장 고르기 | 성공: 보호막 해제 + 낱말 카드 예약 / 실패: 카드 실패, 다음 턴 재도전 |
| 질문: 거기 있음 | 1 | 보기 고르기 + 근거 문장 1개 | 정타 6 |
| 질문: 연결 | 2 | 보기 고르기 + 근거 문장 2개 | 정타 10 |
| 질문: 글쓴이와 나 | 2 | 보기 고르기 + 근거 문장(개수는 문항마다) | 정타 14 (관련 낱말 카드를 붙이면 +4) |
| 낱말 카드 | 1 | 낱말 뜻 서술 | 통과: 방어 5 / 실패: 카드 실패 |
| 요약 봉인 | 2 | 한 문장 요약 서술 | 통과: 적 처치 / 실패: 카드 실패, 다음 턴 재도전 |
| (버튼) 단서 보기 | 1 | 지금 고르는 질문의 틀린 보기 1개 지우기 | "도움받음" 기록 |

- 근거는 **문항마다 정해진 개수만큼** 고른다. 화면이 "근거 문장 N개를 골라 봐"로 알려 주고, 그 개수까지만 고를 수 있다(개수는 카드 규칙이라 정답 암시가 아니다).
- 질문 판정: 해석 O + 근거 O = **정타** / 해석 O + 근거 X = **약타**(절반, 내림) / 해석 X = **실패**(0).
- **낱말 카드 붙이기**(글쓴이와 나 전용): 그 질문의 관련 낱말 카드가 손패에 있으면 붙여서 낼 수 있다. 생각력은 더 들지 않고, 붙인 카드는 뜻 쓰기 없이 버린 더미로 간다(그 카드로 방어는 못 한다). *(가정값, 플레이테스트로 조정)*
- 쓴 질문 카드는 사라진다. 질문을 다 썼는데 요약 봉인이 아직 안 열렸으면, **요약 봉인이 열리고** 실패·약타였던 질문도 **"다시 보기"로 돌아온다**(피해 절반, 도움 기록). 다 맞혔는데 피해가 모자라 막히는 일이 없고, 막힌 학생은 다시 읽고 만회할 수 있다.
- 본문은 전투 내내 보인다. 다시 읽기는 언제나 공짜다.

### 6-3. 확신도
질문 카드는 답을 다 고른 뒤 제출 직전에 **확실 / 애매**를 고른다.

| | 맞음(정타) | 틀림(약타·실패) |
|---|---|---|
| 확실 | 피해 ×1.5 (반올림) | 적의 다음 공격 +3 |
| 애매 | 그대로 | 벌 없음 + 다음 단서 보기 공짜 |

찍고 "확실"을 누르면 손해. 잘 아는 학생은 "확실"로 이득.

### 6-4. 적
- 체력 40(1층) / 45(2층) / 55(3층, 보스). 공격 예고 5~9.
- **적은 요약으로만 쓰러진다.** 질문 피해로는 체력 1에서 멈춘다. → 모든 판에 요약 쓰기가 들어간다.
- 요약 봉인 해금: 적 체력 40% 이하, 또는 질문 카드를 다 썼을 때.

### 6-5. 탑
- 탑 = 화제 하나, 3층(쉬운 글 → 본 글 → 조금 어려운 글). 앞 층 글이 다음 층 배경지식.
- 내 체력은 탑 안에서 이어진다. 층 사이 10 회복.
- 패배하면 그 층부터 다시. 기록은 남는다.
- 진행은 층마다 자동 저장(이어하기).

### 6-6. 이야기 (짧게)
- 설정 원본은 `docs/스토리.md`. 이야기는 장식이 아니라 장치를 설명하는 데만 쓰고, 읽는 시간은 본문 글에 쓴다.
- 주인공은 이름 없이 **"나"**(성별·나이 정하지 않음).
- 화면에 나오는 문구는 네 가지뿐: 탑 들어갈 때 2줄, 탑 다 오르면 2줄, 적 등장 1줄, 적 봉인 1줄. 적은 "처치"가 아니라 **봉인**한다.
- 문구는 낱말 뜻이나 정답의 단서가 되면 안 된다.

## 7. 채점

| 답 | 방식 |
|---|---|
| 보기·근거 고르기 | 보기는 정답과 비교. 근거는 **정해진 개수**를 고르고, **필수 묶음** 후보 중 하나를 다 포함하고, 고른 문장이 모두 **관련 문장**(필수 후보 전체 + 허용 문장) 안에 있으면 정답. 근거는 "답을 뒷받침하는 문장"이지 질문을 되풀이한 문장이 아니다(작업지시서 1-5) |
| 낱말 뜻 서술 | ① 무응답·베끼기 걸러내기 ② 반대 뜻보다 가까울 것 ③ 다른 낱말(기본 팩 전체 + 이 탑의 안개 낱말, 자기 자신 제외) 뜻보다 가까울 것 ④ 이 낱말 뜻과 유사도가 기준 이상 |
| 요약 서술 | ① 길이 10~60자 ② **핵심 개념 포함**(동의어 묶음, 정해진 개수 이상) ③ 모범 요약과 의미 유사도 ④ 오답 요약 앵커보다 가까울 것 |

- 의미 유사도는 브라우저 안에서 도는 문장 임베딩 모델(multilingual-e5-small)과 코사인 유사도로 잰다. 생성형 AI가 아니고, 학생 답은 기기 밖으로 나가지 않는다.
- **유사도 하나로만 판정하지 않는 이유**(v1에서 실측): 짧은 한국어 문장은 내용이 달라도 유사도가 0.8~0.95로 높게 깔리고, 반대말을 비슷하게 본다. 그래서 다른 뜻과의 "비교"와 반대 뜻 앵커를 함께 쓴다. 이 방식으로 모의 답 47개 기준 98%.
- 요약 실패 시 "빠진 것: 꿀벌이 어떻게 되는지" 처럼 빠진 핵심 개념을 알려 준다.
- 기준값은 개발 중 **채점 점검 화면**에서 실제 학생 답을 넣어 보며 정한다.
