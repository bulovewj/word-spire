```text
너는 어린이 교육용 픽셀 아트 게임의 UI/UX 디자이너이자 일러스트레이터야. 웹 게임 ‘낱말탑’의 전체 디자인 명세와 컨셉 아트를 맡아 줘.
기능·학습 규칙·주요 조작 순서와 현재 캐릭터 디자인은 유지하고, 아래 새 세계관과 이미 선택한 한국풍으로 화면·도구·연출을 통일해 줘.
첨부 화면 01~13은 현재 기능 화면이야. 실제로 첨부되지 않은 화면은 봤다고 가정하지 말고 제공된 코드·목록 기준의 검토라고 밝혀 줘.
기존의 낮은 해상도 서양풍 탐험가·꽃 고리·망토 왕·책갈피 봉인은 이전 초안이야. 최신 기준은 한국풍 서고·현대 한복 캐릭터·도깨비/호랑이/여우·호리병 봉인이야.

■ 작업 방식
1단계: 디자인 명세 A~G와 성장·아이템 구상 부록 H, 시안 3장(1280×800 전투 / 390px 전투 / 질문 패널 확대)을 먼저 완성해서 보여 줘.
사용자가 시안을 검토하고 확정한 뒤 그 결정대로 2단계 아트를 진행해. 답변 없이 기다린 시간을 승인으로 간주하지 마.
이미 선택한 그림체와 현재 캐릭터는 보존하고, 1단계에서는 읽기·배치·조작과 새 세계관의 연결을 검토해.

■ 게임 한 줄과 학습 행동
초등 5~6학년이 왕명을 받아 닫힌궁의 요괴 탑에 들어가, 글을 읽고 근거를 찾아 헛소문의 힘을 봉인하는 문해력 카드 게임이야.
한 층 5~10분, 화제 하나의 탑은 3층. 앞 층 글이 다음 층의 배경지식이 돼. 학교 기기에서만 돌고 서버·계정·실행 중 생성형 AI 호출은 없어.
왼쪽(390px는 위)에 번호 붙은 짧은 정보글이 늘 있고, 아래/오른쪽에서 다음 행동을 해.
- 질문 부적패: 보기 4개 중 하나 + 본문 근거 N개 탭 + 확신도(확실/애매) → 정타/약타/실패.
- 낱말 부적패: 뜻을 내 말로 써서 방어. 안개 걷기는 가려진 낱말의 뜻을 짐작하게 해 주는 문장 하나를 고르는 행동.
- 요약 봉인: 적이 약해지거나 질문을 다 쓰면 열려. 한 문장 요약 성공으로 적을 호리병에 봉인해.
- 생각력은 턴마다 3. 비용은 거기 있음 1, 연결 2, 글쓴이와 나 2, 안개 걷기 1, 낱말 1, 요약 2. 단서 보기는 질문 안의 기존 버튼이야.
- 정타 기본 피해는 6/10/14, 낱말 성공 방어는 5, 안개 보호막은 질문 피해 −2. 확실 정타는 ×1.5 반올림, 확실 약타·실패는 다음 적 공격 +3. 애매 약타·실패는 벌 없이 다음 단서 보기 1회가 무료야.
- 턴을 끝내면 예고한 공격을 방어로 막고 남은 피해를 받아. 내 체력에 ‘턴 끝에 받을 피해’를 미리 표시해야 해.
- 글 카드와 매 턴 뽑는 낱말 카드, 다시 보기·도움 기록·층 보상·이어하기는 현행 규칙을 따라. 새 강화 수치를 붙이지 마.

■ 새 전체 스토리: 왕명과 닫힌궁
가상의 나라에서 요괴들이 낱말의 뜻을 흐리고 문장의 앞뒤를 뒤섞어 사람들의 ‘글힘’을 약하게 만든 뒤, 헛소문으로 나라를 어지럽혀.
글힘은 ‘글을 읽고 뜻을 이해하며, 근거를 살펴 판단하는 힘’이야. 문해력을 쉽게 설명하는 이야기 용어이며 새로운 경험치·마나·성적 수치가 아니야.
왕은 글과 도술을 함께 익힌 ‘나’에게 요괴를 봉인하고 되찾은 글을 사람들에게 전하라는 명령을 내려.
평소 문이 잠긴 ‘닫힌궁’은 왕명이 담긴 마패를 지닌 사람에게 길을 열어 줘. 안에는 가려진 글을 화제별로 모은 3층 탑들이 있어.
흐려진 낱말을 되찾고 → 글의 관계를 잇고 → 전체를 내 말로 묶는 과정으로 각 탑을 통과해. 모든 층의 기존 질문 종류와 실제 정보글은 유지해.
왕명은 모험의 계기야. 무엇이 맞는지는 글의 근거를 찾아 판단하고, 마을 사람들이 스스로 읽고 설명할 힘을 되찾는 것이 목적이야.
‘퇴치’는 소동을 멈춘다는 이야기 표현이야. 실제 연출과 결과는 폭력 없이 종이·안개로 접어 호리병에 봉인하는 방식이야.
궁은 현재 탑 선택·소개·완료의 배경으로 표현해. 별도 궁 이동 화면·왕 알현 화면·실제 시간에 따른 입장 제한을 자동으로 추가하지 마.
허구의 소문이나 요괴의 대사를 정보글 본문에 섞지 마. 실제 현대 정보글을 옛 역사 기록이나 요괴의 거짓 주장으로 다시 쓰지 마.

■ 짧은 이야기 문구
왕명 설정 원문: ‘요괴가 글을 흐리고, 헛소문으로 나라를 어지럽혀.’ / ‘닫힌궁으로 들어가 글을 되찾고, 소문을 가릴 길을 열어 줘.’
꿀벌 탑 입장 두 줄: ‘왕명을 받아 닫힌궁의 꿀벌 탑에 들어왔어.’ / ‘요괴가 가린 글에서, 소문을 가려낼 근거를 찾아봐.’
꿀벌 탑 완료 두 줄: ‘세 층의 글을 네 말로 묶어 요괴를 호리병에 봉인했어.’ / ‘되찾은 글을 마을에 전하고, 새 낱말도 챙겨 가자.’
한 탑 완료는 그 화제의 임무 완료야. 나라 전체를 되찾는 결말은 여러 임무를 잇는 전체 이야기이고, 꿀벌 탑 하나를 마쳤다고 모든 사건이 끝난 것처럼 보이지 않게 해.
이야기는 탑 입장 2줄·완료 2줄·요괴 등장 1줄·봉인 1줄로 짧게. 본문 사실·잠긴 낱말의 뜻·정답을 대사로 미리 알려 주지 마.

■ 현재 캐릭터 디자인 — 그대로 유지
주인공은 이름 없이 ‘나’, 성별·나이 없음. 문무를 겸비한 장수의 침착함과 도술을 쓰는 탐험가의 경쾌함이 있어.
검은 머리와 낮게 묶은 머리, 먹빛/짙은 남색의 현대 한복 겹깃 재킷, 크림색 깃, 넉넉한 소매, 비대칭 뒷자락과 세이지 안감.
기능성 허리 스트랩·카드 수납함·카고 주머니·좁아지는 바짓단·발목 신발로 테크웨어 느낌을 살려. 모자·새 갑옷·무기는 더하지 마.
등 위쪽의 금빛 원형 용 문양은 중요한 표식이야. 등판이 보이는 자세에서 읽히게 하고 가슴에 같은 큰 원형 문양을 반복하지 마.
전우치에서 말한 한국 도술의 분위기는 짧은 손목·소매·종이 움직임에 참고해. 기존 영화 인물의 얼굴·모자·무기·복식을 복사해서 캐릭터를 바꾸지 마.

■ 요괴 3종 — 모습은 선택한 한국풍 키 아트 기준
1층 먹안개 도깨비 / 새 아트 id dokkaebi: 둥근 코·굵은 눈썹·짧고 통통한 몸·크림/세이지 조끼. 낱말을 안개로 흐려 놓는 장난꾸러기야.
등장 ‘내 안개를 지나 다음 층에 갈 수 있겠어?’ / 봉인 ‘앗, 내 안개가 호리병 속으로 접히잖아!’
2층 뒤섞는 호랑이 / tiger: 민화풍 둥근 얼굴·황토빛 털·크림 주둥이·먹빛 줄무늬·휘어진 꼬리. 글의 앞뒤를 뒤섞어 길을 헷갈리게 해.
등장 ‘이 문 앞에선 큰소리도 소용없을걸?’ / 봉인 ‘크르릉, 이번에는 네가 길을 찾았구나.’
3층 헛소문 여우 / fox: 크림색 털·뾰족한 귀·라벤더빛 여러 꼬리·먹빛 겹깃 옷. 참말 조각에 거짓을 보태 소문을 퍼뜨리는 우두머리야.
등장 ‘여기까지 왔네. 마지막 문도 열 수 있을까?’ / 봉인 ‘내 소문이 한 장의 부적에 묶이다니!’
실제 동물을 해치는 설정이 아닌 종이·안개의 요괴야. 귀엽고 조금 엉뚱하게, 포효·이빨·위협보다 표정과 실루엣으로 구분해.
기존 게임 데이터의 drought/bloomgap/erasure는 이전 id야. 새 그림은 reader/dokkaebi/tiger/fox로 정리하고, 코드 연결·id 이관은 후속 구현 인계표에 남겨.

■ 카드·도구·봉인
손패는 기존 순서와 가로 크기를 유지한 ‘한지 부적패’ 6종이야: 거기 있음 / 연결 / 글쓴이와 나 / 안개 걷기 / 요약 봉인 / 낱말.
크림색 한지 면, 먹빛 외곽선, 가장자리의 절제된 구름무늬·매듭·금빛 장식. 가운데를 넓고 단색으로 비워 한글은 Galmuri HTML로 얹어.
세 질문 부적패의 크기·테두리·장식 밀도는 같게. 비용은 오른쪽 위에 ‘생각력 N’ 글자를 함께 써. 숫자만 원 안에 넣지 마.
생각력 3/3은 말 무늬가 있는 마패풍 작은 표식 3개로 보여. 왕명 마패는 입장 설정, 작은 표식은 같은 문양을 빌린 자원 표시이며 새 화폐가 아니야.
호리병은 크림·세이지빛 두 둥근 몸체, 잘록한 허리, 나무 마개, 주홍 끈과 네모 종이 꼬리표. 도장은 네모 나무 손잡이·금빛 띠·주홍 인영이야.
요약 성공이 확정된 뒤 0~160ms 부적 펼치기 → 160~480ms 접힌 종이·안개 띠가 호리병 안으로 → 480~720ms 마개를 닫고 도장 찍기.
도장 무늬는 글자 없는 창작 구름·소용돌이야. 장식 인영과 성공 도장을 구분하고, 채점 전 보기·근거·부적에 성공 표식을 보여 주지 마.
움직임 줄이기에서는 모든 이동·접힘·안개 흐름·도장 낙하를 생략하고 닫힌 호리병 정지 그림+‘봉인 성공!’과 대사를 즉시 보여 줘.

■ 꼭 지킬 UI·그래픽 원칙
1. 본문이 주인공이야. 글자 대비·줄 간격·번호·근거 선택 표시를 그림보다 우선하고, 장식·연출이 문장을 가리지 않게 해.
2. 그림은 선택한 세밀한 도트 수준이야. 32×32·48×48 상한에 묶지 말고 실제 표시 크기에 맞는 논리 격자·정수 배율을 정해. 흐린 회화·부드러운 벡터·3D로 바꾸지 마.
3. 잉크 외곽선, 본색 2~3계열과 제한된 단계 음영. 흐림·에어브러시·그라데이션·무지개 효과·연속 반짝임 없이 또렷한 픽셀 군집으로 그려.
4. 글꼴은 Galmuri11(본문·굵게)과 Galmuri9(작은 글씨). 본문 권장 20px/32px, 모바일 18px/29px. 본문을 줄여 그림 자리를 만들지 마.
5. 색 변수 이름은 현행과 같게 정리해. 바탕 #f5eedb, 패널 #fffaf0, 잉크 #2f2a3d, 보조 글자 #686176, 강조 #825515, 선택 rgba(214,163,58,.22).
6. 적 체력·피해 #c34e49, 방어 #3c648f, 내 체력 #6faa76, 약타 #845815, 안개 라벤더 #7a7393, 장식 금빛 #d6a33a. 같은 이름의 토큰 표로 쓰임을 구분해.
7. 제출 전 정답 암시 금지. 보기 4개는 같은 최소 높이·모양·상태 효과를 쓰고, 선택 표시를 성공 색으로 바꾸지 마. 미리보기는 ‘정타 9 / 약타 5 / 실패 0’ 같은 범위만.
8. 색만으로 뜻을 전하지 마. 아이콘·글자·테두리·무늬를 함께 쓰고, 키보드 초점과 선택됨 상태도 구분해.
9. 학교 크롬북·웨일북 1280×800, 아이폰 세로 390px에 맞춰. 모바일은 본문 위·전투 아래, 본문 접기/펼치기 가능, 보이는 터치 대상은 44px 이상.
10. 학생 화면은 한국어 반말, 교사 화면은 존댓말. 뜻을 모를 만한 새 도구 용어만으로 기존 기능 이름을 대체하지 마.
11. 피·상처·무기 타격·공포 연출 없음. 적은 종이·안개로 접혀 호리병으로. 실패는 조용한 결과·이유와 재도전으로 표시해.
12. 실제 구현은 기존 HTML/CSS/React와 미리 만든 PNG 또는 단순 CSS 도형. 새 라이브러리·실행 중 생성형 AI·학생 데이터 외부 전송은 없어.
13. 슬레이 더 스파이어나 다른 기존 게임의 이름·카드 모양·캐릭터·아이콘·그림을 따라 하지 마. 장르 형식만 참고해.
14. 배경 없는 인물·부적·도구·아이콘은 진짜 투명 PNG. 체크무늬를 구워 넣지 마. 투명이 안 되면 단색 #ff00ff 대체임을 밝혀.

■ 첫 플레이의 혼란 — 새 도구에서도 꼭 해결
- 카드 오른쪽 위 숫자는 비용인지 몰랐어. ‘생각력 N’을 함께 써서 마패 무늬 속 숫자로 다시 숨기지 마.
- 적의 예고는 ‘다음 공격 피해 N’으로 읽히게 해. 무기 그림과 숫자만 놓지 마.
- 내 체력의 줄무늬는 ‘턴 끝에 받을 예상 피해’야. 유지하되 −N·현재→예상 체력·설명으로 뜻을 보여 줘.
- 방어는 파란 방패 배지·테두리와 ‘방어 N’, 생각력은 마패풍 표식과 ‘생각력 N/3’로 구분해.
- 부적·도장·호리병을 넣어도 선택/정답, 장식 인영/성공 도장, 실제 체력/방어/예상 피해가 섞여 보이지 않게 해.
```
