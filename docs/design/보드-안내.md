## 열고 고칠 곳 짚기

`docs/design/asset-board.html`을 브라우저로 연다. 파일로 직접 열어도 JS 데이터·시트·캡처를 상대 경로로 읽는다. 개발 서버에서도 `/docs/design/asset-board.html`로 연다. 외부 CDN·새 라이브러리는 없다.
장면 선택 → 펼쳐진 실제 캡처의 번호 또는 옆 ID 누르기 → 같은 ID 강조 → “프레임·조건 보기”로 맨 아래 이동. 원본 링크는 캡처를 원래 크기로 연다. 번호 끄기는 실제 UI를 가리지 않고 살펴볼 때 쓴다.
“모든 그림”에서 상태 또는 ID로 거를 수 있다. 캐릭터·봉인·아이콘·카드 표식 시트 **72개 프레임**은 각각 정확히 2배, 종이 바탕 위에 놓았다. 큰 참조 그림은 별도 상태이며 정수 격자의 게임용 파일로 표시하지 않는다.
수정 요청 예: `EN-tiger-idle: 눈 옆 검은 선을 줄여 줘`, `CH-reader-grip: 부적을 고쳐 쥐는 동작부터`, `BG-floor2: 배경 없이 가자`. 현재 판은 v2-ai다.

## 캡처가 뜻하는 것

- 명세 D의 01~18을 모두 실제 React 앱으로 찍었다. PC는 1280×800, 모바일 전투는 390×844 뷰포트에서 전체 세로를 캡처했다. 타이틀 저장 상태·2층·3층·헛소문 반박도 함께 있다.
- 기존 `current/ds-*.png`를 최신 화면처럼 쓰거나 가짜 React 화면을 새로 만들어 캡처하지 않았다. 별도 검수용 Chrome 프로필에서 시작·근거 선택·단서·정타·낱말 실패·안개·요약 채점·봉인·보상·패배·내 기록·교사 버튼을 차례로 눌렀다.
- 층 이동만은 허용된 저장 상태로 만들었다: 실제 `newRun`의 floor를 바꿔 `saveRun` → 이어하기 → 실제 시작 버튼. 승패·정타·서술 채점은 UI와 현재 엔진·채점을 통했다. 교사 코드는 이 검수의 가상 이름 “검수예시”로 만든 코드이며 실제 학생 자료가 아니다.
- HF/CDN 네트워크는 캡처 세션에서 차단했다. 기존 모델 캐시가 있으면 실제로 의미 채점/준비 배지가 나올 수 있다. 준비·간이·의미 상태는 `GradingBadge.tsx`의 분기를 대장에 적고 캡처에 없는 상태를 합성하지 않았다.
- 번호 상자는 캡처할 때 읽은 DOM 경계 좌표다. 실선은 실제 사용, 회색 점선은 제안이다. 제안 삽화의 여백은 예약 제안일 뿐 현재 앱에 새 공간을 구현한 것이 아니다. 모바일 패배처럼 여백이 없는 경우 해당 제안은 PC와 전체 목록에서 확인한다.

## B4 미리보기의 한계와 규칙

R은 기존 idle 한 칸을 정수 1~2px 옮기는 일정 시연이다. A는 새 blink·grip·hem·tilt·ear·head·tail 실제 프레임을 사용한다. 공격/방어 그림을 무작위 대기 동작에 섞지 않는다.
보드는 재현을 위해 시드 621의 의사난수를 쓰므로 새로 열면 같은 순서다. 실제 게임 일정의 시드는 Claude 연결 때 매번 달리할 제안이다. 기본 R 주기와 위상은 서로 다르다. 캐릭터별 주기는 2400~3400ms로 직접 조절한다. A 간격은 3~7초·±20% 흔들림 후 범위 제한, 동작 길이도 ±20%, 같은 이름 연속 금지다. 사건 버튼은 700ms 우선하며 A를 취소하고 새 간격을 예약한다.
OS 줄이기 > 수동 줄이기 > 사건 > R+A. 모든 대기는 줄이기에서 idle 첫 칸·y=0, 숨은 탭에서는 시간도 멈춘다. 0.1배는 일정 검수용이며 게임 속도 설정 제안이 아니다. 모든 조절은 보드 안에서만 유효하고 저장하지 않는다.

## 재현 소스와 검사 기록

| 파일 | 용도 |
|---|---|
| `board/data.js` | ID·시트 좌표·장면·실제 DOM 자리의 정적 데이터. 파일 열기에도 fetch 없이 동작 |
| `board/source/capture.mjs`·`cdp.mjs` | 전용 로컬 Chrome CDP 9230 + Vite 5176에서 실제 앱 캡처. 실행 시 전용 검수 프로필의 저장을 비움 |
| `board/source/assets.mjs`·`write-docs.mjs` | 프레임·코드 대조 대장 데이터. write-docs는 이전 B 초안 이력이며 실행 금지 |
| `board/source/build-board.mjs`·`render-style.mjs` | sharp 기존 부분 자르기와 HTML 비교 캡처. 새 그림 생성 없음 |
| `board/source/compress-title.mjs` | 보존 포스터 원본 → 런타임 PNG. sharp만 사용, 400,000B 이하 확인 |
| `board/source/qa-board.mjs`·`qa-title.mjs`·`final-board-check.mjs` | 실제 브라우저 배치·번호·필터·동작·접근성 검수 |
| `board/board-audit.json`·`title-audit.json` | 실제 검수 표본·버튼 크기·넘침·일정·정지 기록 |
| `board/title-compression-audit.json` | 포스터 전/후 크기·바이트·SHA·sharp 설정 |

재현 순서: 전용 임시 Chrome 프로필을 CDP 9230으로 실행 → 프로젝트 Vite를 5176으로 실행 → `node docs/design/board/source/capture.mjs` → `build-board.mjs`  → `render-style.mjs`. 스타일 CSS는 `board/style.css`다. 일반 사용자 Chrome이나 실제 학생 기록이 있는 프로필에 캡처 스크립트를 실행하지 않는다.
브라우저 조작 검수는 서로 다른 타이틀·보드 검사를 **순차로** 돌린다. 숨은 탭 정지 정책 때문에 두 검사를 동시에 돌리면 시간 측정에 영향을 준다. 각 소스 파일은 200줄 이하다.

## 최신 제작 범위

사용자의 재제작 요청으로 그림9장·72프레임과 frames.json을 갱신했다. 원본은 imagegen, 후처리는 sharp만 사용했다. src 게임 움직임·전투·엔진·채점·콘텐츠 코드는 수정하지 않았다. 한글 검토본의 생성원본·동작한눈에·그림프레임에서 확인한다. 새 A 일정은 docs 미리보기에만 연결했다.
