## 생성·재현

시작 참조는 기존 승인 이미지 job d7ed328d-33e3-491b-b9f8-48dceb8f1be3. 바람 자세는 GPT Image2.5 job382f8e12-507e-4b99-9136-8068498d078f, 영상은 FLUX3 Video jobfbf36772-c6f2-43b0-b462-89f73f2fe15a. 두 그림 사이의 전환 중 실제 옷자락이 움직이는 구간을 느리게 왕복시켰다. 프레임 혼합·보간·새 라이브러리는 없다.

[제작 폴더](concept/영상-재제작-2판/)에 생성 영상·바람 자세 원본·실제 프롬프트·작업ID·편집 스크립트·이전 영상·검사 기록을 보존했다. 게임 파일 이름은 기존 연결을 유지해 title-idle-korean-v1.mp4지만 내용은 재제작2판이다.

첫 FLUX 재시도(27b993fe-f95a-422d-ac7a-6e032dbf1fc4)는 여전히 변화가 작아 채택하지 않았다. Seedance2.5·Kling3.0은 요금제 제한으로 접수되지 않았다. 이 실패를 숨기고 정지 같은 결과를 최종으로 제공하지 않았다.

검사: PC1280·390px 실제 재생에서 시간과 디코딩 증가, 시작/중간 옷자락 차이·반복·수동/OS 정지·숨은 탭 정지를 확인했다. 초기 OS 줄이기면 영상 요소와 실제 MP4 바이트 요청0(개발용 URL 모듈 요청은 제외). 브라우저 검사는 board/source/qa-video-v2.mjs로 재현한다. 숫자 차이만을 움직임의 증거로 쓰지 않고 추출 PNG를 함께 확인한다.


## 요청7 압축판

최종 게임·검토 영상은 **1280×720·1,763,206B**로 교체했다(전6,213,712B, 71.6% 감소). 기존 Higgsfield sandbox ffmpeg만 사용했다. QP22 후보는2,245,679B라 제외하고 QP24를 선택했다. macOS avconvert720p는4,180,791B,540p는2,674,753B였고 중간화질은532,952B였으나 세부 보존을 위해720p ffmpeg 결과를 썼다. 새 라이브러리·새 생성·src 화면 코드는 바꾸지 않았다.

6초·24fps·144프레임·무음, 첫/끝 디코딩 MD5동일(5300d915e6ad671b3ea687d38b611c78). 포스터 PNG는 그대로며 useTitleMotion/TitleScreen의 preload=none·포스터 우선 표시를 유지한다. 압축 기록은 board/title-video-compression-audit.json, 재현은 concept/영상-재제작-2판/영상-압축-재현.sh. 압축 전 입력과 생성 원본·이전 영상은 컴퓨터에 보관하고 Git에서 제외했다.
