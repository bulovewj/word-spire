# 키아트 4판 기반 AI 재제작 2판

캐릭터 49칸, 봉인·도구·아이콘·카드 표식 23칸, 총72칸. 새로 생성한 9장 원본과 실제 프롬프트를 보존한다.

검토 마스터는 일반128·여우160px. 게임은 기존 Sprite 배율2와 배치를 유지하도록 일반64·여우80px 호환 사본을 쓴다. 게임에 128/160 마스터를 직접 연결하는 배율 전환은 별도 구현이다.

추가 대기 동작은 frames.json에 등록했고 검토 보드에서 실제 그림으로 재생한다. 게임의 불규칙 일정 코드는 이번에 고치지 않았다.

생성이미지-내보내기.mjs는 sharp만 사용해 동일한 정리 결과를 재현한다. 그림을 코드로 새로 그리지 않는다. 원본에는 중간 알파가 있지만 정리시트와 게임용 파일은 0/255만 남긴다.

요청7: 생성 원본 PNG는 로컬 보관·Git 제외. 정리시트에서 그대로 sprite-cleanup.mjs를 실행할 수 있다. 생성 원본이 있을 때 생성이미지-내보내기.mjs를 다시 돌려도 같은 조각 제거 정책을 거쳐 동일한 게임 파일을 만든다. 마스터128/160→게임64/80 nearest, 새 그림·새 동작 없음.
