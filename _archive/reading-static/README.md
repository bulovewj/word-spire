# 낱말탑

짧은 글을 읽고 **해석과 근거를 함께 골라 15층 탑을 오르는 문해력 게임**. 초등 6학년을 대상으로 설계했으며, 기존 서재 배경과 두더지 원화를 사용한다.

## 실행

`index.html`을 브라우저로 열면 시작한다. 설치, 빌드, 서버, 계정, 외부 API가 필요 없다.

로컬 서버로 볼 때:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

- 시작 화면: http://127.0.0.1:4173/
- 저장하지 않는 읽기 체험: http://127.0.0.1:4173/?demo=reading

기존 `?demo=battle` 주소도 읽기 체험으로 연결된다. 체험에서는 실제 모험의 저장 기록을 변경하지 않는다.

## 플레이 방법

1. 한 층의 짧은 글을 읽고 해석 보기 하나를 고른다.
2. 그 해석을 뒷받침하는 문장 1~2개를 글에서 고른다. 필요한 수는 문항마다 표시된다.
3. 해석과 근거를 함께 확인한다. 둘 다 문항의 허용 조합에 맞아야 통과한다.
4. 설명과 낱말의 다른 사용 예를 읽고 다음 층으로 올라간다.

오답이나 근거가 맞지 않는 답으로는 층을 통과할 수 없다. 해석이 맞고 근거만 부족한 경우에는 근거를 다시 읽도록 안내한다. 필요하면 힌트나 풀이를 볼 수 있으며, 도움을 본 것만으로 통과되지는 않는다.

| 읽기 활동 | 내용 | 문항 수 |
|---|---|---:|
| 문맥 낱말 | 문장 안에서 낱말의 뜻 알아내기 | 4 |
| 문장 연결 | 연결어·원인·지시어·비교 읽기 | 4 |
| 내용 추론 | 행동으로 마음 짐작하기, 중심 내용 요약하기 | 2 |
| 근거 판단 | 사실과 추측, 광고, 조사 범위, 출처, 안내문의 예외 판단하기 | 5 |

‘여유’는 시간과 공간, ‘드러나다’는 마음과 정보라는 새 문맥에서 다시 등장한다. 수첩에서 해결한 과제의 낱말·뜻·다른 상황의 예문을 돌아볼 수 있다.

## 기록과 저장

- `첫 시도에 해결`, `다시 읽고 해결`, `도움받아 해결`을 구별한다. 힌트나 풀이를 본 뒤의 해결은 첫 시도 독립 해결로 기록하지 않는다.
- 실제 모험은 `localStorage`의 `wordSpireReadingV1`에 자동 저장한다. 현재 선택한 해석·근거, 시도 수, 도움 여부도 이어진다.
- 기존 속담 전투의 저장 키와 분리되어 있다. 새 읽기 모험을 시작하면 현재 읽기 모험 기록은 새로 시작한다.
- 기록은 해당 브라우저에만 남는다. 계정·외부 전송·기기 간 동기화는 없으며, 저장을 사용할 수 없는 환경에서도 플레이할 수 있다.

## 구현과 자료

- `js/data-reading-words.js`, `js/data-reading-reasoning.js`: 사전 제작한 자작 글 15개와 해석·근거·해설
- `js/reading-state.js`: 모험 상태, 이어하기, 기록 집계, 저장 검증
- `js/reading-engine.js`: 해석과 근거의 결합 판정, 도움, 다음 층 진행
- `js/reading-presentation.js`: 수첩·해설·결과의 표시용 문자열
- `js/ui.js`: 시작·읽기·탑 지도·결과 화면과 수첩 조작
- `css/reading.css`: 읽기 화면·수첩·결과의 반응형 배치
- `assets/README.md`: 기존 원화·프롬프트·표시 방식
- [문해력 개편 설계](docs/문해력-개편.md): 바꾼 이유, 문항 구성, 판정 규칙, 참고 자료와 한계

과거 덱빌딩 구현은 `_archive/legacy-battle/`에 이력으로 남아 있다. 현재 진입점은 이 파일들을 불러오지 않는다. 원화 PNG는 유지하며 일부 표시 영역은 CSS로 제한한다.

## 확인

```sh
node tools/check-game.cjs
```

읽기 판정 검증(`tools/check-reading.cjs`)과 HTML·CSS 리소스, 스크립트 문법, DOM 연결 검증을 함께 실행한다. 15문항의 보기·근거 180조합에서 정답만 통과하고, 오답 진행 차단·도움과 재시도 기록·중복 제출·보기 순서·저장 복원·체험 저장 격리가 작동하는지 확인한다.

격리된 Chrome에서 실제 DOM 클릭으로 오답과 잘못된 근거의 진행 차단, 재시도, 힌트·해설, 수첩 열기와 Escape 닫기, 지도, 15층 완주, 자동 저장·이어하기, 새 모험 취소, 체험 저장 격리를 확인했다. `file://` 실행에서도 이미지 로드와 풀이를 확인했으며, 1440·768·400px 화면에서 가로 넘침이 없고 검사 중 JavaScript 예외가 없었다.

현재는 읽기 연습용 시제품이다. **초등 6학년의 문해력 향상 효과와 문항 난도는 아직 학습자 대상으로 검증하지 않았다.** 해결 기록은 이 게임 안에서의 활동 기록이며 표준화된 문해력 점수가 아니다.
