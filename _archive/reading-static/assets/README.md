# 낱말탑 이미지 에셋 — v1

기획서, 실제 카드·괴물 데이터, 기존 `concept/word-spire-key-art-v1.png`를 참조해 제작한 파스텔 도트풍 시안.
생성 도구: 내장 image_gen. 실행 중 AI 호출 없이 사용하는 정적 PNG 파일이다.

| 파일 | 용도 |
| --- | --- |
| `concept/word-spire-battle-v1.png` | 5층 숨바꼭질 두더지 전투 화면의 구성·색감 기준 |
| `backgrounds/library-battle-v1.png` | UI와 괴물을 제거한 서재 전투 배경 |
| `enemies/e04-hide-and-seek-mole-v1.png` | 두더지와 펼친 책을 묶은 캐릭터 원화. 배경 제거 필요 |
| `cards/card-base-lavender-v1.png` | 그림·문자·비용을 별도로 얹을 빈 카드 바탕 원화. 배경 제거 필요 |

두더지와 카드 틀은 투명 PNG를 요청하고 배경 제거를 재시도했으나, 생성 도구가 체크무늬를 포함한 RGB 이미지를 반환했다. 따라서 두 파일은 제작용 원화이며, 바로 합성할 수 있는 투명 에셋이 아니다. 게임에 적용하기 전에 외곽 배경을 제거하고 실제 알파 채널을 검증해야 한다.

## 화면 구성 기준

- 크림색 돌과 종이, 세이지·라벤더, 따뜻한 금빛 조명. 형태는 어두운 잉크색 윤곽선으로 구분한다.
- 상단 자원, 왼쪽 상황과 태그, 오른쪽 괴물, 하단 손패 5장으로 배치한다.
- 시안은 `e04`의 세 번째 요구 문장과 카드 `c01`, `c02`, `c03`, `c17`, `c23`을 사용한다.
- 보스 체력 40/40과 집중력 30/30은 화면 구성용 예시 값이다. 실제 진행 상태는 코드에서 표시한다.
- 카드의 금빛 강조는 시각적 제안이며 현재 게임에 구현된 동작이 아니다.
- UI 문장, 카드 이름·뜻·태그, 비용·공격력, 체력바는 실제 적용 시 HTML/CSS로 표시한다. 기준 화면에 구워진 텍스트를 재사용하지 않는다.
- 생성 이미지는 도트풍 고해상도 원화다. 애니메이션 프레임이나 일정한 픽셀 격자로 정리된 스프라이트 시트는 아니다.

## 후속 제작 단위

1. 카드 그림: 프레임·문자 없는 삽화로 각각 제작해 동일한 카드 바탕 위에 배치한다.
2. 괴물: `js/data-enemies.js`의 ID별로 대기 자세를 만들고 크기와 바닥 기준점을 통일한다.
3. UI 장식: 상황 패널, 버튼 바탕, 자원 아이콘을 독립 이미지로 만든다.

각 이미지와 같은 이름의 `.prompt.txt`에 최종 생성 프롬프트를 보관한다.
## 게임 화면 적용

`index.html`의 전투 화면에 배경, 두더지, 카드 바탕을 연결했다.
- 두더지: `css/asset-clips.css`의 외곽선으로 체크무늬 배경을 숨긴다. 원본 PNG는 RGB 그대로 보존한다.
- 외곽선 재생성: 기존 Pillow 환경에서 `python3 tools/build-asset-clip.py`. 게임 실행에는 Python이 필요 없다.
- 카드 틀: CSS 배경 크기와 위치를 조정해 체크무늬 여백을 제외한다.
- 카드 삽화 5종: 기준 화면의 삽화 부분만 CSS로 표시한다. 문자·비용은 HTML 데이터로 별도 표시한다.
- 두더지 외 괴물에는 공통 책 문양을, 삽화가 없는 카드에는 종류 문양을 사용한다. 추가 원화를 연결할 수 있다.
- `?demo=battle`로 열면 원본 기획의 5층 두더지 보스전을 체험할 수 있다. 체험은 저장 기록을 바꾸지 않는다.
