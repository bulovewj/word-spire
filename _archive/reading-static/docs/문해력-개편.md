# 낱말탑 문해력 개편

짧은 글의 뜻을 해석하고 그 판단의 근거를 찾아야 한 층을 통과하는 15층 읽기 게임으로 바꾸었다. 초등 6학년을 대상으로 설계했으며 기존 서재 배경, 두더지, 파스텔 카드 원화를 활용한다.

## 바꾼 이유

이전 버전은 속담과 관용구 카드의 태그·공격 수치가 진행의 중심이었다. 상황과 맞지 않는 답도 피해를 줄 수 있었고, 승리 여부만으로 학생이 글을 이해했는지 확인하기 어려웠다. 같은 표현을 다른 상황에서 해석하는 연습도 부족했다.

현재 버전의 핵심 행동은 `글 읽기 → 해석 고르기 → 근거 찾기 → 설명 확인 → 다음 층`이다. 플레이어의 진행과 읽기 판단을 직접 연결한다. 속담 지식이나 카드 공격력은 통과 조건에 사용하지 않는다.

## 학습 활동과 15층 구성

| 층 | 활동 | 읽을 내용과 판단 |
|---:|---|---|
| 1 | 문맥 낱말 | 출발 준비에서 ‘여유’가 가리키는 시간 |
| 2 | 문맥 낱말 | 말과 몸짓 사이에서 긴장이 ‘드러나다’ |
| 3 | 문장 연결 | ‘그러나’ 앞뒤의 예상과 다른 흐름 |
| 4 | 내용 추론 | 발표 전후 행동에 근거한 마음의 변화 |
| 5 | 문맥 낱말 | 책장에서 ‘여유’가 가리키는 공간 |
| 6 | 내용 추론 | 메모지 활동의 방법과 결과를 함께 요약하기 |
| 7 | 문장 연결 | 시간 순서와 장소를 옮긴 원인 구별하기 |
| 8 | 문장 연결 | ‘이 방법’이 가리키는 과정 연결하기 |
| 9 | 근거 판단 | 분실물 기록에서 확인한 사실과 추측 구별하기 |
| 10 | 문맥 낱말 | 기록을 정리해 정보가 ‘드러나다’ |
| 11 | 근거 판단 | 광고의 주장과 직접 확인한 기능 구별하기 |
| 12 | 근거 판단 | 네 명의 대답을 반 전체의 생각으로 넓히지 않기 |
| 13 | 근거 판단 | 소문의 전달 횟수 대신 확인할 출처 찾기 |
| 14 | 문장 연결 | ‘반면’으로 연결된 두 길의 차이 비교하기 |
| 15 | 근거 판단 | 기본 안내와 이번 주 예외 조건 함께 적용하기 |

‘여유’는 시간에서 공간으로, ‘드러나다’는 마음에서 정보로 문맥을 바꾸어 다시 만난다. 앞서 외운 답을 반복하기보다, 이번 글에서 무엇을 설명하는지를 확인하도록 설계했다. 이 구성 자체가 새로운 글로의 학습 전이를 입증하는 것은 아니다.

## 판정 원칙

- 해석 보기 하나와 해당 문항에서 요구하는 근거 1~2문장을 고른다.
- `answerId`와 `evidenceSets`의 조합이 모두 맞아야 통과한다. 근거를 고른 순서는 판정에 영향을 주지 않는다.
- 해석이 틀리거나 근거가 맞지 않으면 진행되지 않는다. 오답 누적 피해나 다른 카드의 힘으로 통과하는 경로는 없다.
- 해석이 맞고 근거만 맞지 않으면 그 차이를 알려 주고 근거를 다시 읽게 한다.
- 답과 근거가 모두 준비되지 않은 제출은 풀이 시도로 세지 않는다. 동일한 조합을 연속으로 다시 제출해도 시도 수를 늘리지 않는다.
- 힌트는 읽을 단서를 제공하고, 풀이 보기는 해석과 근거를 설명한다. 도움을 본 뒤에도 직접 해석과 근거를 골라야 통과한다.
- 보기는 문항을 시작할 때 순서를 섞는다. 저장을 복원할 때에는 기존 보기 순서를 유지한다.

문항 데이터는 3~4문장의 자작 글, 세 보기의 개별 피드백, 허용 답과 근거 조합, 힌트, 설명, 낱말·뜻·다른 상황의 예문으로 구성된다. 실행 중에 문제를 생성하거나 외부 API로 채점하지 않는다.

근거 채점은 데이터에 명시한 조합만 인정한다. 따라서 콘텐츠를 고칠 때에는 다른 타당한 근거를 부당하게 막지 않는지 먼저 검토해야 한다. 타당한 대안 조합은 모두 추가하고, 한 문장으로 충분한 경우에는 근거 수를 하나로 줄인다. 질문의 범위가 모호하면 채점 규칙으로 덮지 말고 질문이나 글을 고친다.

## 피드백과 기록

| 기록 | 기준 |
|---|---|
| 첫 시도에 해결 | 힌트·풀이를 보지 않고 첫 번째 완성된 답과 근거 제출로 통과 |
| 다시 읽고 해결 | 도움을 보지 않고 답이나 근거를 고쳐 통과 |
| 도움받아 해결 | 힌트 또는 풀이를 본 뒤 통과 |

각 기록에는 문항, 선택한 해석·근거, 시도 수, 힌트·풀이 사용 여부를 보관한다. 첫 시도 통과 수와 해결한 문항 수를 구별하며, 같은 문항의 반복 제출로 해결 기록이 중복 쌓이지 않는다.

수첩에는 해결한 과제의 낱말과 뜻, 새로운 상황에서의 예문을 모은다. 결과 화면에서는 읽기 활동 유형별 해결 기록을 돌아본다. 이 기록은 게임 안에서의 관찰 자료이며 표준화된 능력 점수나 학습 효과 측정치가 아니다.

## 실행·화면·저장

- 순수 HTML·CSS·JavaScript로 실행한다. 빌드 도구, 로그인, 서버 API, 런타임 AI가 없다.
- `index.html`을 직접 열거나 정적 서버에서 실행한다. 필요한 글·그림·코드는 프로젝트 내부 파일이다.
- 화면 식별자는 `title`, `battle`, `map`, `result`다. `battle`은 기존 코드의 이름을 유지한 읽기 플레이 화면이다.
- 정상 모험은 `wordSpireReadingV1`에 자동 저장한다. 현재 층뿐 아니라 미완성 선택, 도움 여부, 시도 수까지 이어할 수 있다.
- 기존 속담 전투의 저장 키는 읽기 기록으로 전환하지 않는다. 새 모험은 현재 읽기 기록을 새로 시작한다.
- `?demo=reading`과 호환 주소 `?demo=battle`은 저장하지 않는 체험이다. 체험 결과로 정상 모험 기록을 덮어쓰지 않는다.
- 저장 데이터는 복원 전에 검증한다. 저장소를 사용할 수 없어도 현재 세션의 플레이는 가능하다.

현재 구현은 `data-reading-words.js`, `data-reading-reasoning.js`, `reading-state.js`, `reading-engine.js`, `reading-presentation.js`, `ui.js`를 사용한다. 이전 `data-cards.js`, `data-enemies.js`, `state.js`, `battle.js`, `map.js`, `reward.js`, `presentation.js`는 기록으로 남기고 현재 진입점에서 불러오지 않는다.

## 검증과 아직 확인하지 못한 점

`node tools/check-reading.cjs`는 15문항의 보기·근거 180조합을 순회하며 판정과 진행 차단을 확인한다. 도움·재시도의 분리, 중복 제출, 보기 섞기, 15층 완료, 저장 복원·불일치 검출, 비저장 체험도 검사한다.

`node tools/check-game.cjs`는 위 판정 검사에 리소스·스크립트 문법·DOM 연결 검사를 더한다. 격리된 실제 Chrome에서 클릭을 통한 15층 완주, 오답·근거 오류, 도움, 수첩·지도, 저장·이어하기, 새 모험 취소, 체험 격리, `file://` 실행을 확인했다. 1440·768·400px에서 가로 넘침이 없으며 검사 중 JavaScript 예외가 없었다.

이 검증은 프로그램이 지정한 규칙대로 동작하는지 확인한다. 문항의 교육적 타당성이나 문해력 향상을 증명하지는 않는다. 현재는 초6 학습자 대상 난도, 재미의 지속성, 새 글로의 전이, 장기적인 학습 효과를 검증하지 않은 시제품이다.

후속 검토에서는 학생이 선택 이유를 직접 설명하는지, 새 글에서도 근거를 찾는지, 일정 시간이 지난 뒤에도 적용하는지를 관찰할 필요가 있다. 현재 15문항은 짧은 선택형 과제이므로 긴 글 읽기, 직접 요약문 쓰기, 토론 등의 활동 전체를 대신하지 않는다.

## 설계 방향의 참고 자료

미국 IES/WWC의 4~9학년 읽기 중재 지침은 낱말 지식, 글에 관한 질문과 답, 짧은 글의 요지 찾기, 이해 상태 점검을 권고한다. 이번 게임에서는 문맥 속 낱말 해석, 질문에 답하기, 요약, 피드백 후 다시 읽기를 설계하는 데 참고했다. [Providing Reading Interventions for Students in Grades 4–9](https://ies.ed.gov/ncee/wwc/practiceguide/29)

OECD의 PISA 2018 읽기 평가틀은 정보 찾기, 이해·추론, 정보의 질과 출처 평가, 여러 글의 정보 통합을 다룬다. 이번 게임에서는 확인 가능한 근거, 광고·소문 구별, 안내문 두 개의 조건 결합을 설계하는 데 참고했다. [PISA 2018 Reading Framework](https://www.oecd.org/en/publications/pisa-2018-assessment-and-analytical-framework_b25efab8-en/full-report/component-3.html)

위 자료는 활동의 설계 방향에 대한 참고다. IES 지침의 중재 효과를 이 게임의 효과로 간주하지 않으며, PISA 평가틀은 초6용 게임의 효과 검증 자료가 아니다. 한국어 초등 6학년을 대상으로 한 이 게임의 검증은 별도로 필요하다.
