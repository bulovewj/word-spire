# 카드 초안 (M2용 12장)

M2에서 `js/data-cards.js`로 옮길 원본. 형이 낱말을 바꾸고 싶으면 이 문서를 먼저 고치고 코드에 반영한다.

## 균형 설계 규칙
- 비용 0~1 = 흔한 표현, 약한 데미지. 비용 2~3 = 어려운 표현, 강한 데미지
- 뜻이 좁은 카드(태그 1개)일수록 강하게, 넓은 카드(태그 3개)는 약하게 — **범용 카드는 약하다**가 이 게임의 규칙이다
- 시작 덱 10장 = 아래 ★ 표시 카드들

| id | 낱말 | 종류 | 비용 | 힘 | 태그 | 뜻 | 시작덱 |

## 효과 부여 (M3~M6)
- `card_002 발이 넓다` → `draw1` (인맥이 넓으니 카드를 한 장 더 뽑는다)
- `card_006 손을 놓다` → `block4` (막는 카드)
- `card_004 티끌 모아 태산` → `energy1` (다음 턴 생각 +1)
