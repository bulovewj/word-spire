# 디자인 검토본 전달 규칙

사용자 지시 · 2026-10-22. **앞으로 디자인을 변경하거나 생성하면 사용자 검토본을 프로젝트 맨 위 `검토/`에 한글 파일명으로 둔다.**

- 사용자가 처음 열 파일은 항상 `00-최종검토.html`이다. 최신 보드·비교·원화·영상·수정요청 링크를 함께 갱신한다.
- 실제 게임에서 읽는 영문 ID·파일명을 바꾸어 연결을 끊지 않는다. 검토 사본의 파일명을 한글로 정하고 대장에 ID와 대응시킨다.
- `그림원본/`: 승인 원화·게임용 시트·시작 배경·영상. `그림프레임/`: 기존 시트를 프레임별로 자른 원래 해상도 PNG. `장면캡처/`: 실제 게임 캡처. `비교자료/`: 기존 그림의 부분 비교. `보조자료/`: 글꼴·CSS·JS·검수·갱신 도구.
- 승인 원화 / 현재 게임용 초안 / 미정 제안을 명확히 구분한다. “최종 검토본”은 최신 전달본이라는 뜻이며 디자인 승인 완료를 뜻하지 않는다.
- 새 에셋은 `보조자료/검토-이름표.mjs`에 한글 이름을 등록하고 `node 검토/보조자료/검토본-갱신.mjs`를 실행한다. 보드의 ID·파일·상태도 먼저 최신으로 맞춘다.
- 새로 생성한 그림과 원본 프롬프트도 한글 이름으로 이 폴더에 먼저 검토본을 제공한다. 아직 대장에 없는 단일 그림이라도 한글 이름·판을 붙여 넣고 첫 화면에 링크한다. 런타임 연결·승인 여부는 별도로 기록한다.
- 같은 파일이 바뀌면 갱신 도구가 이전 검토 묶음을 `이전판/날짜-일련번호/`에 보존한다. 사용자가 적은 `수정요청.md`는 갱신 도구가 덮어쓰지 않는다.
- 이 폴더는 상대 경로만 쓰고 글꼴까지 포함한다. 폴더를 통째로 복사해도 브라우저에서 열려야 한다. 새 라이브러리·외부 업로드는 필요 없다.

현재 검토 대상: 사용자가 요청한 키아트4판 기반 AI 재제작2판. 생성원본/에는 실제 AI 원본·프롬프트, 동작한눈에/에는 캐릭터별4열 모음, 그림프레임/에는 정리된128·160px 마스터 프레임을 둔다. 게임 호환64·80px 파일과 구분한다.

요청7: 이전판/과 생성 원본 PNG·원본 영상은 파일을 지우지 않고 Git 추적에서 제외한다. 현재 검토 첫 화면·정리된 마스터·프레임·비교 자료·프롬프트는 Git에 남긴다. 갱신기는 원본 PNG를 다시 검토본에 복제하지 않으며 원본이 없는 Git 체크아웃에서도 동작한다.
