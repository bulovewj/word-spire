# 컴퓨터·패드 전투 배치 제안

2026-11-08 · 미정 제안 · 실제 게임 연결 전

[직접 눌러 보는 시안](15-컴퓨터와패드-레이아웃.html)

첨부한 모바일 게임의 큰 전투 무대, 마주 보는 인물, 체력·다음 공격 예고,
여러 행동을 동시에 펼쳐 보는 구성을 낱말탑에 맞췄다.
가방 대신 본문과 카드·낱말 묶음을 배치했다.

| 화면 | 배치 |
| --- | --- |
| 컴퓨터·노트북 | 왼쪽 본문 / 가운데 전투와 생각력·턴 종료 / 오른쪽 카드·낱말 |
| 패드 가로·세로 | 위 전투와 생각력 / 아래 왼쪽 본문·오른쪽 카드 |
| 휴대폰 | 전투 → 생각력 → 본문 → 카드. 생각력 줄은 스크롤 중 위에 고정 |

시안 컨테이너 너비 1180px 이하에서 2열, 620px 이하에서 1열로 바뀐다.
상단의 패드 가로·세로 버튼으로 넓은 컴퓨터에서도 좁은 배치를 볼 수 있다.
실제 화면이 더 좁으면 그 너비에 맞춘다.

본문 18px, 현재 인물 원화·128/160px 크기, 정답 공개 시점과 게임 규칙은 유지했다.
짙은 초록 무대는 종이색 본문·카드와 구분하며, 궁의 창살은 CSS로 만든 배경 제안이다.
별도 그림을 생성하지 않았다. 긴 3층 본문이 전투 무대 높이를 늘리지 않는다.

## 직접 확인할 수 있는 것

- 질문 카드 → 보기·근거·확신도 선택 → 제출
- 안개 걷기, 낱말 뜻 입력, 턴 끝내기
- 1·2·3층과 큰 여우 보스
- 패배 후 같은 층 재시작
- 화면 크기 전환과 휴대폰 본문 접기

시안은 기존 `BattleScreen`, 엔진 `createBattle`·`reduce`를 그대로 재사용한다.
낱말·요약은 기존 간이 채점을 사용하며, 의미 모델은 시작하지 않는다.
저장 기능 없이 층마다 새 전투를 여는 검토본이다. 실제 탑 진행·보상 화면은 이 시안의 범위 밖이다.

## 파일

- 검토 ID: `LAYOUT-desktop-tablet`
- `보조자료/컴퓨터패드-시안.tsx`: 시안 진입 화면·폭 전환·층 초기화
- `보조자료/컴퓨터패드-배치.css`: 검토본 전용 스타일
- `보조자료/컴퓨터패드-만들기.mjs`: 기존 Vite로 오프라인 HTML 재생성
- `컴퓨터패드배치/`: 화면 크기별 실제 브라우저 캡처
- `보조자료/컴퓨터패드-검사기록.json`: 크기별 동작·넘침 검증

`node 검토/보조자료/컴퓨터패드-만들기.mjs`로 재생성한다.
HTML에 스크립트·글꼴·인물 그림을 포함해 파일을 직접 열어도 동작한다.
게임 연결 시 이 배치 스타일을 실제 화면에 옮기는 작업이 필요하다.

검증: 1512·1280·1024·820·390px에서 외부 HTTP/HTTPS 요청을 막고 확인했다.
각 크기에서 18px 본문, 가로 넘침 없음, 질문 선택·낱말 입력·3층·재시작을 확인했다.
135개 기존 테스트와 앱 빌드, 시안 TypeScript 검사도 통과했다.
