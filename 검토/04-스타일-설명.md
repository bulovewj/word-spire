# 스타일 기준 — AI 재제작2판

2026-10-22 · [최종 검토본](../../검토/00-최종검토.html) · [비교 PNG](02-그림-스타일-비교.png).

키아트4판과 주인공 앞뒤를 참조해 imagegen으로 캐릭터·도구·카드 시트9장을 새로 생성했다. 기존의 수작업 코드 도트는 교체했다. 검토 마스터와 실제 생성 원본·제출 프롬프트를 모두 남겼다.

| 파일 | 일반 / 여우 | 쓰임 |
|---|---|---|
| 검토 마스터 | 128 / 160px | 세부 검토·후속1배 연결용. 프레임별 원래 크기 PNG 제공 |
| 게임 호환 | 64 / 80px ×2 | 현행 Sprite 배율·배치를 그대로 유지. 시트 앞5/4칸 순서도 보존 |
| 크기 후보A | 96 / 120px ×1 | 더 여유 있지만 세부가 줄어드는 후보 외곽선 |
| 크기 후보C | 160 / 200px ×1 | 기존 정보 칸을 침범해 비추천 |

비교의 회색 외곽선은 자리 크기만 비교한다. 실제 390px 캡처의 그림은 새 게임 호환본이다. 검토 그림은128·160px 마스터라 게임 호환본보다 점 수가4배다. 게임 직접 연결에는 기존 scale2를1로 바꾸는 후속 작업이 필요하며 이번에 화면 코드는 고치지 않았다.

팔레트는 시트 전체에 공유해 포즈마다 색이 달라지지 않게 했다. 불투명색은 각 시트15색 이하(카드틀10색), 밝음·본색·그늘 중심의 면 음영이다. 모든 정리 PNG는 알파0/255, 투명RGB0, 잉크 #2f2a3d를 포함한다. nearest 내보내기, dither0, 정수 배율만 사용한다. 생성 원본에는 중간 알파가 있어 참고 보존용이며 게임에서 읽지 않는다.

호랑이는 눈과 줄무늬를 분리하고, 도깨비는 둥근 코·세이지 매듭옷, 여우는 긴 주둥이·먹색 도포·크림/라벤더 꼬리, 주인공은 검은 묶은 머리·흰 깃·세이지 옷자락·등판 원형 용을 유지했다. 작은 원본에서 복잡한 용 문양은 모양을 알아보는 수준으로 단순해진다.

원본과 내보내기 재현 소스는 concept/재제작-2판/에 있다. 알파·크기·색 수 기록은 src/ui/sprites/sprite-audit.json이다. 새 배경과 장면 삽화는 만들지 않았다.


요청7 정리판: 마스터28프레임에서 옆 칸 조각50덩어리(2247px)를 지웠다. 가장 큰 몸통 덩어리·색·바닥선은 그대로다. 몸과 분리된12px 이하 조각은 마스터34→22·게임49→25이며, 남긴 것은 연기·땀·종이·움직임 표시·아이콘 강조점이다. 이유와72프레임 전후는 [조각 검사](스프라이트-조각-검사.md), [비교](조각정리-전후비교.html)를 본다. 원본 PNG·원본/이전 영상과 검토 이전판은 컴퓨터에 보관하고 Git 추적에서만 제외했다. 현재 비교·정리 마스터·프레임·프롬프트·스크립트·최종 파일은 Git에 남긴다.
